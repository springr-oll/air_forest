# air_forest mockup

ブラウザだけで動く「紙芝居モック」です。

## できること（フロントのみ）

- Excel（`.xlsx`）または `.csv` を選択してローカルで読み込み
- シートのプレビュー表示
- “達人レビュー”の体裁で、構造化したレビュー文（モック）を生成
- 元シートを壊さず、レビュー用シート `_air_forest_review` を追加したExcelをダウンロード

## 使い方

### A) ローカルHTTPサーバ経由（推奨）

PowerShell でリポジトリ直下から起動:

- `python -m http.server 5173`

ブラウザで開く:

- `http://127.0.0.1:5173/mockup/index.html`

その後:

1. Excelファイルを選択
2. `レビュー生成（モック）` を押す
3. `Excel（レビューシート追加）をダウンロード` を押す

### B) ファイル直開き（環境によっては動く）

`mockup/index.html` をブラウザで開く

## 注意

- LLM/DBは未接続です（固定テンプレ＋簡易ヒューリスティック）
- SheetJS（xlsx）はCDNから読み込みます。オフライン環境では動かない場合があります。
